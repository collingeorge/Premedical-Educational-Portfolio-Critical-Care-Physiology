# What is guideline-recommended, general knowledge or clinical practice?

Reviewed 28 October 2026. This page classifies the ICU/CTICU care, laboratory and equipment examples. It separates direct source recommendations from general knowledge and from the authored case applications. A supported recommendation is not the same as one standardized regimen for all patients.

## Labels used beside the examples

| Label | Meaning |
|---|---|
| Guideline recommendation | A source explicitly recommends or suggests the stated action. Strong, conditional and ungraded statements are identified separately, with population limits. |
| Consensus guidance | The source gives consensus recommendations; no GRADE strength or international-standard status is invented. |
| General clinical knowledge | Source-supported physiology, diagnostic interpretation, equipment function or measurement limitations. This is not a treatment protocol. |
| Context-dependent clinical practice | A choice or care sequence depends on the actual condition, procedure, trajectory, goals, available expertise and local protocol. |
| Synthetic example | Fictional patient, numerical result or original decision tree illustrating an application. It is not an observed case or a society-prescribed regimen. |

In this repository, the standardized element of the author-created case format is documentation and organization. Clinical recommendations below have only the authority and scope of their named sources; this classification does not declare a legal standard of care.
